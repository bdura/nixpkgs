# Agent workspace

Knowledge base and bookkeeping for this project. See `wiki/`, `ideas/`, `specs/`,
`plans/` and `issues/`.

- [wiki](wiki/index.md) — knowledge base articles.
- [ideas](ideas/index.md) — feature proposals awaiting a specification.
- [specs](specs/index.md) — full specifications for future features.
- [plans](plans/index.md) — implementation plans for those features.
- [issues](issues/index.md) — potential issues detected while working.

Working material:

- `inbox/` — staging area for source documents awaiting ingestion; a document
  moves out of it into `sources/` when ingested.
- `sources/` — persistent source documents, committed and append-only:
  add to them, never modify them.
- `.repos/` — external repositories cloned for study (gitignored).
